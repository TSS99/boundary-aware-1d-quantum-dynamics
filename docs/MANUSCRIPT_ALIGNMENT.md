# Manuscript alignment

Items in the manuscript that must be updated to match this repository. Each is a
change in substance, not wording, unless marked otherwise.

Numerical values should be taken from
`results/paper/metadata/paper_values.tex`, which is generated by
`scripts/reproduce.py` and can be `\input` directly. Do not retype numbers.

## Terminology and claims

| # | Item | Required change |
|---|---|---|
| 1 | Classical vs circuit | Distinguish explicitly between NumPy/SciPy spectral propagation, Qiskit statevector emulation, logical circuit construction and analytical resource estimates. A SciPy DST propagation must not be described as a quantum-circuit execution. |
| 2 | QST implementation status | The transform is now a validated DST-II circuit (odd extension on a `4N` register, two ancillas, agreement below 1e-10 with the analytical matrix). Any earlier text describing a "QST-compatible pathway" or resting on an extended-register QFT must be replaced. |
| 3 | Hardware | State plainly that no hardware run was performed. Circuit diagrams are not hardware results. |
| 4 | Fidelity | Reported fidelities are simulator diagnostics. Measuring them experimentally needs an overlap protocol or tomography, at `1/eps^2` shot cost. |
| 5 | Complexity claims | Every complexity statement must be conditioned on state preparation, potential and kinetic phase synthesis, measurement, precision and repetitions. A polynomial-size QFT alone does not establish an efficient end-to-end algorithm. |
| 6 | Advantage claims | Remove any unqualified speedup or advantage claim. See `PRIOR_WORK.md` for the list of what is and is not claimed. |

## Physics and numerics

| # | Item | Required change |
|---|---|---|
| 7 | Gaussian convention | `exp[-(x-x0)^2 / (4 sigma^2)]`, with `sigma` the standard deviation of `\|psi\|^2`. Use this everywhere; a `2 sigma^2` denominator anywhere is inconsistent. |
| 8 | Infinite-well fidelity | Explain that near-unity fidelity there is **structural**: the DST-II rows are the analytical sine eigenmodes, and the propagator shares the reference eigenvalues. It is not independent evidence of continuum accuracy. |
| 9 | Zero-well step sweep | Must not be presented as Trotter convergence. With `V = 0` the Dirichlet splitting is exact and the sweep is flat at round-off. |
| 10 | New benchmark | Add the tilted well `V(x) = F(x - L/2)`, `F = 5`, `t_max = 2`, as the genuine Trotter benchmark under hard walls. Report the fitted slope with its fit window. |
| 11 | Boundary comparison | Add the direct periodic-versus-Dirichlet experiment as the central quantitative result. |
| 12 | Convergence reporting | Every slope must carry its fit interval, the number of points, `R^2` and the expected theoretical slope. State that the fit excludes the pre-asymptotic first point. |
| 13 | Reference independence | State which reference each result uses and whether it shares a basis or a method with the propagator. |
| 14 | Boundary terminology | Near-wall probability is not leakage. Wrap-around probability and wall residual are the diagnostics that indicate a wrong topology. |

## Resources

| # | Item | Required change |
|---|---|---|
| 15 | Qubit counts | Report data, ancilla and total separately. The Dirichlet circuit uses `n_q + 2` qubits; an earlier table reported `n_q = 6` for a circuit occupying 8 wires. |
| 16 | Step composition | `r` steps use one half-phase, `r-1` full phases, one half-phase and `r` kinetic blocks — not `r` copies of the five-block step. |
| 17 | Synthesis assumptions | Distinguish structured `O(n^2)` synthesis from the generic `DiagonalGate` upper bound, and say which figure is quoted. |
| 18 | Connectivity | Quote all-to-all and linear nearest-neighbour counts, with the transpiler settings and seed. |
| 19 | Scaling | Report scaling across register sizes, not a single qubit count. |
| 20 | State preparation | Report separately; it is exact amplitude encoding and exponential in the qubit count. No efficient-preparation claim. |
| 21 | Approximate QFT | If mentioned, give the accuracy cost alongside the gate saving. |
